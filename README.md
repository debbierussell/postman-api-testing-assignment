## Overview

This repository contains the complete submission for my API Testing assignment. I used **Postman** to test the **DummyJSON API**, which is a free REST API designed for testing and prototyping.

The project demonstrates:
- **JWT Authentication** (Login and token management)
- **Full CRUD Operations** (Create, Read, Update, Delete)
- **Environment Variables** for dynamic testing
- **Automation** using Pre-request Scripts
- **Collection Runner** with comprehensive test scripts
